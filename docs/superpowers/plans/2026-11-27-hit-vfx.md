# Hit VFX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hit sites emit tagged events. Rule sets owned by each emitter turn those events into layered GPU particle effect scenes, with a global toggle, three quality levels, and an area-load warm-up so the first spawn never hitches.

**Architecture:** `Fx` (static) builds an `FxEvent`: action + source context (`fx_tags()`) + result (the target's `surface` / `fx_tags` metadata). It hands the event to `Vfx` (static), which walks the source's `VfxSet` (own rules, then includes; every match plays; an `exclusive` match stops the walk) and spawns effect scenes under the current scene. Sustained effects (`Fx.hold`) are refreshed every physics frame and fade out when a frame passes without a refresh. `GameArea` warms every reachable effect scene, plus the projectile, on load.

**Tech Stack:** Godot 4.7.2 GDScript, GPUParticles3D + ParticleProcessMaterial, headless `-s` SceneTree tests, one windowed `-s` check.

**Spec:** `docs/superpowers/specs/2026-11-27-hit-vfx-design.md`

## Global Constraints

- `Fx`, `FxEvent`, `Vfx`, `VfxSet` and `VfxRule` never reference the `World` autoload. Enemy, WeightBody, MovingPlatform and Projectile call them, and `-s` tests compile those before autoloads exist.
- Settings: `ahra/vfx/disable` (bool, default false) and `ahra/vfx/quality` (int, Low=0 / Mid=1 / High=2, default 2). Both go in `project.godot` `[ahra]` and are read at every spawn.
- Quality: every `GPUParticles3D` gets `amount_ratio` = 0.35 / 0.65 / 1.0. Nodes in group `vfx_high` are removed below High, nodes in `vfx_mid` below Mid.
- Effect scene = a `Node3D` root (no script) with `GPUParticles3D` children (other nodes allowed). +Y is aligned to the normal. Held (looping) effects use `one_shot = false`. Every effect has at least one `vfx_mid` and one `vfx_high` child, so the three quality levels look different. Keep them simple (unshaded billboards, small meshes) and clearly different from each other.
- Surface = metadata `surface` (StringName) on the node or its nearest ancestor that has it, else `&"default"`. `fx_tags` = metadata (PackedStringArray) found the same way.
- Hit actions `shot_hit`, `melee_hit` and `attack_hit` also carry the tag `impact`. The attacker's set draws the impact, the target's set only its reaction.
- Don't edit `demo/demo.tscn` or `demo/builder/`.
- Run Godot exactly as in CLAUDE.md (`timeout`, the console exe, the `NOISE` grep). A new `class_name` needs one `--editor --quit-after 400` run before `-s` tests see it.
- Every new `.gd` gets its `.uid` sidecar committed (the editor run creates them).

## Review Focus

1. **A rule with an empty `effect`, or a set that includes itself (inspector slips)**: the rule is skipped and the walk ends without an error or hang. Test in Task 1 `rules`.
2. **The source freed before its projectile lands, or a null source**: the default set plays, no `is_instance_valid` error. Test in Task 3 `player`.
3. **The held source freed or teleported** (weight memory restore, a kill zone): the effect fades out, or jumps without streaking (`reset_physics_interpolation`). Test in Task 2 `hold`.
4. **The toggle switched off while a drag effect runs**: it fades out within a frame, and comes back on the next refresh once switched on. Test in Task 2 `hold`.
5. **A spawn during a scene change** (no current scene, or the area queued for deletion): nothing spawns, no error. Test in Task 1 `quality`.

  - `class_name Fx extends RefCounted`, static:
    - `const IMPACTS: Array[StringName] = [&"shot_hit", &"melee_hit", &"attack_hit"]`, `const RECENT := 4`, `static var recent: Array[FxEvent]` (newest last).
    - `static func emit(source: Node3D, action: StringName, at: Vector3, normal := Vector3.ZERO, target: Object = null, extra: Array[StringName] = []) -> FxEvent`: builds the event, records it in `recent`, calls `Vfx.play(e)`, returns it. Its body has the comment `# audio later: Sfx.play(e)`.
    - `static func tags_for(source: Node3D, action: StringName, target: Object, extra: Array[StringName]) -> Dictionary`: action, `impact` for the IMPACTS actions, extras, `source.fx_tags()` when the source is valid and has the method, then the result: `surface(target)`, each `meta_tags(target)` entry, and `enemy` / `player` / `weight` when the target is in that group. A null target adds no result tags.
    - `static func surface(node: Object) -> StringName` and `static func meta_tags(node: Object) -> PackedStringArray`: walk `node` and its ancestors (Nodes only).
    - `static func debug_text() -> String`: one line per recent event, `"fx: " + action + sorted other tags`.
    - `static func clear() -> void`.
  - `@tool class_name VfxRule extends Resource`: `@export var all: Array[StringName]`, `@export var none: Array[StringName]`, `@export var effect: PackedScene`, `@export var exclusive := false`, `@export var align_to_normal := true`, `func matches(tags: Dictionary) -> bool` (false when `effect` is null). Keeps `resource_name` set to a summary, e.g. `"shot_hit metal → impact_metal"` (`!` before each `none` tag, ` (only)` when exclusive), the way `npc/npc_step.gd` does.
  - `class_name VfxSet extends Resource`: `@export var rules: Array[VfxRule]`, `@export var include: Array[VfxSet]`, `const MAX_DEPTH := 8`, `func flat() -> Array[VfxRule]` (own rules, then each include's flat, recursion capped at MAX_DEPTH), `func pick(tags: Dictionary) -> Array[VfxRule]`, `func scenes() -> Array[PackedScene]` (unique, non-null).
  - `class_name Vfx extends RefCounted`, static:
    - `const DISABLE := "ahra/vfx/disable"`, `const QUALITY := "ahra/vfx/quality"`, `enum Quality { LOW, MID, HIGH }`, `const RATIO := [0.35, 0.65, 1.0]`, `const PAD := 0.2`.
    - `const DEFAULT := preload("res://vfx/sets/impacts.tres")`.
    - `static func set_of(source: Object) -> VfxSet`: `source.vfx` when the source is valid and that property is a non-null VfxSet, else DEFAULT.
    - `static func play(e: FxEvent) -> Array[Node3D]`: spawned roots, `[]` when disabled or there's no tree.
    - `static func spawn(scene: PackedScene, at: Vector3, normal: Vector3, up: Vector3, align: bool) -> Node3D`: parent `tree.current_scene`; null when there's no current scene or it is queued for deletion.
    - `static func apply_quality(root: Node, q: int) -> void`, `static func quality() -> int`, `static func life(root: Node) -> float` (max over GPUParticles3D of `lifetime / speed_scale`), `static func clear() -> void`.
